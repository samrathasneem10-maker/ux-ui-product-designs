UX/UI Product Design

📌 Project Overview

This project focuses on creating a user-friendly and visually engaging digital product through a structured UI/UX design process.

The project explores the user journey, interface design, and overall user experience.

🎯 Objectives

- Understand user needs and requirements
- Design a clear user journey
- Create intuitive and user-friendly interfaces
- Develop wireframes and UI designs
- Improve the overall user experience

🔄 Design Process

1. User Research
2. User Journey Mapping
3. Wireframing
4. UI Design
5. Prototyping
6. Usability Improvement

🛠️ Tools & Technologies

- Figma
- UI/UX Design
- User Journey Mapping
- Wireframing
- Prototyping
